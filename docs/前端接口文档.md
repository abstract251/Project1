# 缘遇 YUANYU · 前端接口文档（前后端契约）

| 项目 | 内容 |
| --- | --- |
| 文档版本 | v1.0 |
| 对应前端 | `front/`（首页 / 发现页 / 个人资料 / 聊天 / 注册登录） |
| 说明 | 当前前端全部使用 **MOCK 数据**（各 js 文件顶部有 `MOCK` 注释标记）。后端按本文档实现后，前端将 `fetch` 替换 mock，**接口路径与字段保持不变** |

---

## 0. 通用约定

### 0.1 基础信息

- Base URL：`http://<host>:<port>/api`
- 请求头：`Content-Type: application/json`（上传照片使用 `multipart/form-data`）
- 时间格式：`"yyyy-MM-dd HH:mm:ss"`（本地时区）
- 图片字段：返回可访问的 URL 字符串，前端直接用于 `<img>` / `background-image`

### 0.2 统一响应格式

```json
{
  "code": 0,          // 0 = 成功，非 0 见错误码表
  "message": "ok",
  "data": { }
}
```

### 0.3 认证

- 登录 / 注册成功后返回 `token`，前端存于 `localStorage`，后续请求头携带：
  ```
  Authorization: Bearer <token>
  ```
- 返回 `code=1002`（登录过期）时，前端跳转注册登录页

### 0.4 分页约定

- 查询参数：`page`（从 1 开始）、`pageSize`（默认 20）
- 游标参数：`beforeId` / `afterId`（聊天记录用，见 5.2）
- 响应统一包含：`list`、`total`、`hasMore`

## 1. 错误码表

| code | 含义 |
| --- | --- |
| 0 | 成功 |
| 1001 | 参数错误（缺参 / 格式错误） |
| 1002 | 未登录或登录已过期 |
| 1003 | 无权限（如修改他人资料） |
| 2001 | 账号已注册 |
| 2002 | 验证码错误或已过期 |
| 2003 | 账号或密码错误 |
| 2004 | 手机号格式错误 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

## 3. 发现页（`front/html/discover.html`）

### 3.1 候选用户列表（含筛选）

```
GET /users/recommend
```

查询参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| ageMin | int | 最小年龄，默认 18 |
| ageMax | int | 最大年龄，默认 45 |
| distance | int | 距离上限（公里），0 = 不限 |
| tags | string | 兴趣标签，逗号分隔，如 `旅行,摄影` |
| page / pageSize | int | 分页 |

响应 `data`：

```json
{
  "list": [
    {
      "id": 1,
      "name": "苏晴",
      "age": 28,
      "city": "杭州",
      "job": "UI 设计师",
      "photo": "https://.../photo.jpg",   // 无照片时为 null，前端用渐变占位
      "tags": ["摄影", "咖啡", "艺术展"],
      "mutual": "你们都喜欢爵士乐"          // 共同点文案，无则 null
    }
  ],
  "total": 36,
  "hasMore": true
}
```

> 前端当前 MOCK 位置：`front/js/discover.js` 中的 `ALL_USERS`。

### 3.2 滑动上报（左滑 / 右滑）

```
POST /users/{id}/swipe
```

请求体：

```json
{ "action": "like" }   // like = 感兴趣（右滑），nope = 不感兴趣（左滑）
```

响应 `data`：

```json
{
  "matched": false      // true = 双方互感兴趣，前端展示匹配成功动画，并可引导进入聊天页
}
```

### 3.3 筛选选项（可选，可前端硬编码）

```
GET /meta/filters
```

响应 `data`：

```json
{
  "ageRange": [18, 50],
  "distances": [{ "value": 0, "label": "不限距离" }, { "value": 5, "label": "5 公里内" }],
  "tags": ["旅行", "摄影", "健身", "美食", "阅读", "咖啡", "宠物", "音乐", "运动", "艺术"]
}
```

### 4.2 更新资料

```
PUT /profile/me
```

请求体（部分字段即可）：

```json
{
  "name": "苏晴",
  "bio": "新的自我介绍……",
  "tags": ["旅行", "摄影"],
  "turnOns": ["真诚", "幽默感"],
  "info": { "height": "168 cm" }

```

### 4.3 上传照片

```
POST /profile/photos
```

- 请求：`multipart/form-data`，字段 `file`（图片文件）、`label`（可选，如"咖啡馆"）
- 响应 `data`：`{ "id": 5, "url": "https://.../p5.jpg" }`

### 4.4 删除照片

```
DELETE /profile/photos/{photoId}
```

响应 `data`：`{ "ok": true }`

```
GET /profile/completeness
```

响应 `data`：

```json

  "score": 85,
  "missing": ["还差一张生活照", "完善职业信息"]
}
```

## 5. 聊天页（`front/html/chat.html`）

### 5.1 会话列表（供后续"消息列表页"使用）

```
GET /chats
```

响应 `data`：

```json
{
  "list": [
    {
      "chatId": 201,
      "userId": 1002,
      "name": "顾言",
      "avatar": "https://.../avatar.jpg",
      "lastMsg": "周六下午吧，我先去占位置 📷",
      "lastTime": "2026-01-01 09:30:00",
      "unread": 0
    }
  ]
}
```

### 5.2 聊天记录（向上翻页加载）

```
GET /chats/{chatId}/messages?beforeId=<游标>&pageSize=20
```

- `beforeId`：当前最早一条消息的 id，加载更早的消息；不传则取最新一页
- 响应 `data`：

```json
{
  "list": [
    {
      "id": 501,
      "from": "them",              // them = 对方，me = 我
      "type": "text",              // text / image / system
      "content": "今天的日落特别好看 🌇",
      "time": "2026-01-01 21:04:00"
    }
  ],
  "hasMore": false
}
```

> 前端当前 MOCK 位置：`front/js/chat.js` 中的 `MESSAGES`。

### 5.3 发送消息

```
POST /chats/{chatId}/messages
```

请求体：

```json
{ "type": "text", "content": "好呀，周末怎么样？" }
```

响应 `data`：`{ "id": 502, "time": "2026-01-01 09:12:00" }`

### 5.4 标记已读

```
POST /chats/{chatId}/read
```

请求体：`{}`　响应 `data`：`{ "ok": true }`

### 5.5 实时通道（推荐 WebSocket）

```
WS /ws?token=<token>
```

前端事件（JSON 字符串）：

| 事件 | data | 说明 |
| --- | --- | --- |
| `message` | Message（同 5.2 结构） | 新消息到达，前端气泡闪烁提示 |
| `typing` | `{ "chatId": 201, "userId": 1002, "typing": true }` | 对方正在输入 |
| `read` | `{ "chatId": 201, "readTime": "..." }` | 对方已读回执 |

> 若暂不实现 WebSocket，可用轮询替代：前端定时 `GET /chats/{chatId}/messages?afterId=<最新id>` 增量拉取，并 `POST /chats/{chatId}/typing`（body `{ "typing": true }`）上报输入状态。

## 6. 注册 / 登录页（`front/html/signup.html`）

### 6.1 发送短信验证码（可选，手机号注册用）

```
POST /auth/sms
```

请求体：`{ "phone": "13800000000" }`　响应 `data`：`{ "ok": true }`

> 60 秒重发限制由后端控制（返回 1001 或自定义 code），前端做按钮倒计时。

### 6.2 注册

```
POST /auth/register
```

请求体：

```json
{
  "account": "13800000000",      // 手机号或邮箱
  "password": "abcd1234",
  "gender": "female",            // male / female / secret
  "birthday": "1998-06-12",
  "code": "123456"               // 手机号注册时的验证码，邮箱注册可省略
}
```

响应 `data`：

```json
{
  "token": "eyJhbGciOi...",
  "user": { "id": 1001, "name": "苏晴", "avatar": null }
}
```

### 6.3 登录

```
POST /auth/login
```

请求体：`{ "account": "13800000000", "password": "abcd1234" }`

响应 `data`：同 6.2（`token` + `user`）。

### 6.4 退出登录

```
POST /auth/logout
```

请求头带 token。响应 `data`：`{ "ok": true }`

### 6.5 获取当前用户

```
GET /auth/me
```

请求头带 token。响应 `data`：`{ "user": { "id": 1001, "name": "苏晴", "avatar": "..." } }`

### 6.6 刷新 token（可选）

```
POST /auth/refresh
```

请求体：`{ "refreshToken": "..." }`　响应 `data`：`{ "token": "..." }`
